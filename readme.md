## 📝 Exercice 2 : Liste des Types HTML5 Utilisés

Pour cet exercice, plusieurs types de champs de saisie HTML5 (`<input type="...">`) ont été intégrés dans les formulaires du site afin d'optimiser l'expérience utilisateur (UX) et d'assurer une validation native des données :

| Type HTML5 | Champ / Emplacement | Description & Rôle |
| :--- | :--- | :--- |
| **`text`** | Nom, Prénom, Adresse | Saisie de texte brut à ligne unique. |
| **`email`** | Adresse e-mail | Validation automatique du format de messagerie (`exemple@email.com`). |
| **`tel`** | Numéro de téléphone | Saisie des numéros (déclenche le clavier numérique sur mobile). |
| **`number`** | Quantité de commande | Saisie de valeurs numériques contrôlées (`min`, `max`). |
| **`password`** | Mot de passe | Masquage des caractères lors de la connexion/inscription. |
| **`date`** | Date de livraison / Réservation | Sélection d'une date via un calendrier HTML5 interactif. |
| **`search`** | Barre de recherche | Champ dédié à la recherche rapide de pâtisseries. |
